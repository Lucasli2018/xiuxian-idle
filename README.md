# 仙途挂机 · 修仙放置

珊瑚橙 × 水墨国风的修仙放置挂机小游戏（纯前端）。

美术图为 AI 生成（已去除水印），珊瑚橙主题与系列项目保持一致。

## 玩法

- **打坐修炼**：点击主角吐纳灵气
- **门人弟子**：自动产出灵气的生成器，每 25 级产出翻倍
- **功法法宝**：一次性永久强化（点击 / 产出倍率）
- **境界突破**：炼气 → 筑基 → … → 仙人（10 境），每次突破全局 ×3
- **转世轮回**：散尽修为换「道韵」，每点道韵永久 +2% 全局产出
- **离线挂机**：离线也在涨灵气（效率 50%，上限 8 小时）

## 数值公式

```
购买成本   = baseCost × 1.15 ^ level
产出 / 秒  = Σ(等级 × 基础产出 × 2^⌊等级/25⌋) × 功法倍率 × 境界倍率 × 道韵倍率
突破消耗   = 200 × 10 ^ 当前境界
道韵收益   = ⌊ √(本世累计灵气 / 100万) ⌋
道韵加成   = 1 + 0.02 × 道韵
离线收益   = 产出/秒 × min(离线时长, 8h) × 0.5
```

## 本地运行

无任何构建与依赖，直接用浏览器打开 `index.html`，或：

```bash
npx serve .
```

存档保存在 `localStorage`（键 `xiuxian_idle_save_v1`），支持导出 / 导入存档码。

## 部署

纯静态站点，可直接部署到 Cloudflare Pages / 任意静态托管（构建命令留空，输出目录为仓库根目录）。
